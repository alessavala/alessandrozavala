HTML, CSS y JavaScript para principiantes: lo básico en una tarde

Los tres lenguajes de cualquier página web, explicados con ejemplos que puedes copiar. Aprende qué hace cada uno y escribe tu primera página hoy.

Por César Alessandro Zavala25 de noviembre de 20267 min de lectura

Todas las páginas web del mundo, desde la de tu taquería favorita hasta Amazon, usan los mismos tres lenguajes: HTML, CSS y JavaScript. No necesitas dominarlos para tener un sitio, pero entenderlos te da poder: puedes corregir un texto, cambiar un color o entender qué te propone la IA. En esta guía los vas a conocer con ejemplos reales.

La analogía de la casa

Piensa en una página web como una casa:

  • HTML son los muros, las puertas y las ventanas: la estructura.
  • CSS es la pintura, los muebles y la decoración: el diseño.
  • JavaScript es la electricidad: lo que hace que las cosas se muevan y respondan.

Una casa sin pintura sigue siendo casa. Una página sin CSS sigue funcionando, sólo que se ve fea. Por eso siempre se empieza por el HTML.

Lo que necesitas para empezar

  • Una computadora.
  • Un editor de texto. Te recomiendo Visual Studio Code, que es gratis.
  • Un navegador, como Chrome.

No necesitas instalar nada más. Creas un archivo, lo guardas con terminación .html y lo abres con el navegador.

HTML: la estructura

HTML funciona con etiquetas. Una etiqueta abre y cierra un elemento, y lo que está en medio es el contenido:

<h1>Tacos Don Pepe</h1>
<p>Los mejores tacos de Tampico desde 1998.</p>
<a href="https://wa.me/521234567890">Pide por WhatsApp</a>

Las etiquetas más usadas:

  • h1 a h6: títulos. Sólo debe haber un h1 por página: el título principal.
  • p: párrafos.
  • a: enlaces. El atributo href indica a dónde llevan.
  • img: imágenes. El atributo alt describe la imagen para Google y para personas con discapacidad visual.
  • ul y li: listas.
  • header, nav, main, footer: las secciones grandes de la página.

La estructura mínima de una página

Toda página tiene este esqueleto:

<!DOCTYPE html>
<html lang="es-MX">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Tacos Don Pepe | Tampico</title>
  <meta name="description" content="Tacos de bistec y trompo en Tampico.">
</head>
<body>
  <h1>Tacos Don Pepe</h1>
</body>
</html>

La parte de head no se ve en la pantalla, pero es clave: ahí van el título que aparece en Google, la descripción y la línea viewport, que hace que la página se vea bien en celulares.

CSS: el diseño

CSS dice cómo se ven los elementos. Se escribe con selectores y propiedades:

body {
  font-family: Arial, sans-serif;
  color: #222;
  margin: 0;
}
h1 {
  color: #0a1f44;
  font-size: 40px;
}
a {
  background: #25d366;
  color: white;
  padding: 12px 20px;
  border-radius: 10px;
  text-decoration: none;
}

Con esas líneas ya tienes letra legible, un título azul y un botón verde de WhatsApp. El CSS se puede poner dentro de una etiqueta style en el head o en un archivo aparte.

Diseño que se adapta al celular

Más de la mitad de las visitas vienen de celulares. CSS permite cambiar el diseño según el tamaño de pantalla con algo llamado media queries:

@media (max-width: 700px) {
  h1 { font-size: 28px; }
}

Esto significa: "si la pantalla mide menos de 700 píxeles, haz el título más pequeño". Te explico más en cómo hacer tu sitio responsive.

Flexbox y grid

Para acomodar elementos en columnas existen dos herramientas modernas. Flexbox sirve para alinear cosas en una fila o columna, como un menú. Grid sirve para cuadrículas, como una galería de productos. Con una línea como esta haces una cuadrícula que se adapta sola:

.productos {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(250px, 1fr));
  gap: 20px;
}

JavaScript: el comportamiento

JavaScript hace que la página responda a lo que hace el visitante. Un ejemplo sencillo, una calculadora de precio con envío:

<input id="precio" type="number" placeholder="Precio">
<button onclick="calcular()">Calcular</button>
<p id="total"></p>
<script>
function calcular() {
  const precio = Number(document.getElementById("precio").value);
  const total = precio + 99;
  document.getElementById("total").textContent = "Total con envío: $" + total;
}
</script>

Lo que pasa: cuando alguien da clic en el botón, JavaScript lee el número, le suma 99 y muestra el resultado. Con esta misma lógica se hacen calculadoras de ROAS, cotizadores o formularios.

Usa JavaScript con moderación

Cada línea de JavaScript tarda en descargarse y ejecutarse. Muchos sitios lentos lo son porque cargan demasiados scripts. Regla práctica: si algo se puede hacer con HTML y CSS, no uses JavaScript.

Cómo practicar

  • Haz una página de tu negocio con título, descripción, tres servicios y un botón de WhatsApp.
  • Cámbiale colores y tipografía con CSS.
  • Agrega una pequeña calculadora con JavaScript.
  • Ábrela en tu celular para ver cómo se ve.

En cómo crear tu primera página web con HTML te guío paso a paso con un proyecto completo.

Herramientas que te ayudan

  • Las herramientas de desarrollador del navegador: clic derecho y "Inspeccionar" en cualquier página. Puedes ver y probar cambios sin romper nada.
  • La IA: pídele que te explique una línea de código que no entiendes o que corrija un error. Es como tener un maestro disponible todo el día.
  • MDN Web Docs: la documentación de referencia de Mozilla, gratuita y en español.

Errores comunes de principiante

  • Olvidar cerrar una etiqueta.
  • Poner varios h1 en la misma página.
  • Imágenes enormes que hacen lenta la página.
  • No probar en el celular.
  • Copiar código sin entender qué hace.

Cómo se conectan los tres en un archivo real

En proyectos pequeños puedes tener todo en un solo archivo HTML: la estructura en el body, los estilos en una etiqueta style dentro del head y el JavaScript en una etiqueta script al final del body. Es la forma más simple de empezar y de compartir un ejemplo.

Cuando el proyecto crece, conviene separarlos: un archivo index.html, uno estilos.css y uno app.js. El HTML los enlaza con una etiqueta link para el CSS y una etiqueta script para el JavaScript. Separarlos permite que el navegador guarde en memoria los estilos y los scripts, y que no los descargue otra vez en cada página. También facilita que varias páginas compartan el mismo diseño: cambias un color en un archivo y se actualiza todo el sitio.

HTML semántico: por qué importa el nombre de cada etiqueta

Podrías construir una página entera sólo con etiquetas div, que son contenedores genéricos, y se vería igual. Pero no es buena idea. Las etiquetas semánticas le dicen al navegador, a Google y a los lectores de pantalla qué es cada cosa:

  • header: el encabezado del sitio o de una sección.
  • nav: el menú de navegación.
  • main: el contenido principal, sólo uno por página.
  • article: una pieza independiente, como un artículo o un producto.
  • section: una sección temática dentro de la página.
  • footer: el pie de página.

Usarlas bien mejora la accesibilidad y ayuda a que los buscadores entiendan la estructura de tu contenido. Es de las mejoras más baratas que puedes hacer al SEO técnico de tu sitio.

Colores, tipografía y espacios: lo mínimo de diseño

No necesitas ser diseñador para que tu página se vea profesional. Tres reglas te llevan muy lejos:

  • Pocos colores: uno principal de tu marca, uno para botones y grises para el texto. Más de cuatro colores suele verse desordenado.
  • Una o dos tipografías: una para títulos y otra para texto, o la misma en distintos grosores. Usa un tamaño de texto de al menos 16 píxeles para que se lea bien en celular.
  • Espacio en blanco: deja aire entre secciones y alrededor de los botones. Las páginas amontonadas se sienten baratas.

En CSS, los espacios se controlan con dos propiedades: margin, el espacio fuera de un elemento, y padding, el espacio dentro. Entender la diferencia resuelve la mitad de los problemas de diseño de los principiantes.

Cómo pedirle ayuda a la IA con código

Cuando algo no funcione, no le digas a la IA sólo "no sirve". Dale contexto: pega el código, explica qué esperabas que pasara y qué pasó en realidad, y copia el mensaje de error si aparece en la consola del navegador. Con esa información la respuesta suele ser precisa. Y pídele siempre que te explique el cambio, no sólo que te dé el código corregido: así aprendes y la próxima vez lo resuelves tú.

Preguntas frecuentes

¿Cuánto tiempo tarda aprender lo básico?

En una tarde puedes hacer una página sencilla. En unas semanas de práctica constante puedes construir sitios completos.

¿HTML es un lenguaje de programación?

Técnicamente es un lenguaje de marcado, porque describe contenido en lugar de dar instrucciones. JavaScript sí es un lenguaje de programación.

¿Tengo que aprender los tres?

Para tener tu sitio con IA, entender HTML y lo básico de CSS es suficiente. JavaScript lo aprendes cuando necesites interactividad.

Conclusión

HTML, CSS y JavaScript son el alfabeto de internet. No necesitas ser experto: con entender qué hace cada uno ya puedes leer tu sitio, hacer cambios sencillos y trabajar con la IA sabiendo lo que pides. Abre un editor, copia los ejemplos de esta guía y haz tu primera página hoy.
