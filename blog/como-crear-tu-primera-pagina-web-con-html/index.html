Cómo crear tu primera página web con HTML paso a paso

Un proyecto completo para principiantes: la página de tu negocio con portada, servicios, ubicación y botón de WhatsApp, lista para subir a internet.

Por César Alessandro Zavala25 de noviembre de 20268 min de lectura

En esta guía vamos a construir juntos, de principio a fin, la página web de un negocio. No es un ejemplo abstracto: al final tendrás un archivo que puedes subir a internet con tu información. Uso como ejemplo una hamburguesería, pero puedes cambiar los textos por los de tu negocio.

Lo que vas a construir

Una página de una sola sección larga, de las llamadas one page, con:

  • Encabezado con el nombre del negocio y un menú.
  • Portada con frase principal y botón de WhatsApp.
  • Sección de productos o servicios.
  • Sección de horarios y ubicación.
  • Pie de página con redes sociales.

Es exactamente lo que necesita un negocio local para empezar a recibir clientes desde Google.

Paso 1: prepara tu carpeta

Crea en tu computadora una carpeta llamada mi-sitio. Dentro, crea un archivo llamado index.html y una carpeta llamada img para tus fotos. El nombre index.html es importante: es el archivo que los servidores muestran por defecto cuando alguien entra a tu dominio.

Abre la carpeta con Visual Studio Code u otro editor de texto.

Paso 2: el esqueleto

Copia esto en index.html:

<!DOCTYPE html>
<html lang="es-MX">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Hamburguesas La Esquina | Tampico</title>
  <meta name="description" content="Hamburguesas al carbón en Tampico. Pide a domicilio por WhatsApp.">
</head>
<body>
</body>
</html>

Guarda y abre el archivo con tu navegador. Verás una página en blanco, pero en la pestaña aparecerá el título. Ese título y la descripción son lo que Google mostrará en sus resultados, así que escríbelos pensando en lo que tu cliente buscaría.

Paso 3: el encabezado y el menú

Dentro de body agrega:

<header>
  <a href="#" class="logo">La Esquina</a>
  <nav>
    <a href="#menu">Menú</a>
    <a href="#ubicacion">Ubicación</a>
  </nav>
</header>

Los enlaces que empiezan con almohadilla llevan a una sección de la misma página. Más adelante crearemos las secciones con esos nombres.

Paso 4: la portada

La portada es lo primero que se ve. Debe responder en segundos qué vendes, dónde y cómo pedir:

<section class="portada">
  <h1>Hamburguesas al carbón en Tampico</h1>
  <p>Carne 100% de res, pan artesanal y entrega en Tampico y Madero.</p>
  <a class="boton" href="https://wa.me/521234567890?text=Hola,%20quiero%20pedir">Pedir por WhatsApp</a>
</section>

Cambia el número por el tuyo con código de país, sin espacios ni signos. El texto después de text= es el mensaje que aparecerá escrito; los espacios se reemplazan por %20.

Paso 5: los productos

<section id="menu">
  <h2>Nuestro menú</h2>
  <div class="productos">
    <article>
      <img src="img/clasica.jpg" alt="Hamburguesa clásica con queso" loading="lazy">
      <h3>Clásica</h3>
      <p>Carne, queso, lechuga y tomate. $120</p>
    </article>
    <article>
      <img src="img/doble.jpg" alt="Hamburguesa doble con tocino" loading="lazy">
      <h3>Doble con tocino</h3>
      <p>Doble carne, tocino y queso. $160</p>
    </article>
  </div>
</section>

Fíjate en tres detalles: usamos h2 para el título de sección y h3 para cada producto, respetando la jerarquía; cada imagen tiene un texto alt descriptivo; y loading="lazy" hace que las imágenes se carguen sólo cuando el visitante se acerca a ellas, lo que acelera la página.

Prepara tus fotos

Antes de ponerlas en la carpeta img, redúcelas a unos 1,200 píxeles de ancho y comprímelas. Una foto directa del celular puede pesar varios megas y hacer lentísima tu página. Herramientas gratuitas como Squoosh lo hacen en segundos.

Paso 6: ubicación y horarios

<section id="ubicacion">
  <h2>Horarios y ubicación</h2>
  <p>Lunes a domingo de 1:00 p.m. a 11:00 p.m.</p>
  <p>Calle Ejemplo 123, Col. Centro, Tampico, Tamaulipas.</p>
  <a href="https://maps.google.com/?q=Hamburguesas+La+Esquina+Tampico">Ver en Google Maps</a>
</section>

Escribir tu dirección y tu ciudad en texto ayuda a que Google entienda dónde estás y te muestre en búsquedas locales.

Paso 7: el pie de página

<footer>
  <p>Hamburguesas La Esquina · Tampico, Tamaulipas</p>
  <a href="https://www.instagram.com/tu-cuenta">Instagram</a>
</footer>

Paso 8: dale estilo

Dentro del head, antes de cerrar, agrega una etiqueta style con este CSS básico:

<style>
body { margin: 0; font-family: Arial, sans-serif; color: #222; }
header { display: flex; justify-content: space-between; padding: 16px 24px; background: #111; }
header a { color: white; text-decoration: none; margin-left: 16px; }
.portada { padding: 80px 24px; text-align: center; background: #fff4e6; }
.portada h1 { font-size: 42px; margin: 0 0 12px; }
.boton { display: inline-block; background: #25d366; color: #fff; padding: 14px 24px; border-radius: 12px; text-decoration: none; font-weight: bold; }
section { padding: 48px 24px; max-width: 1000px; margin: 0 auto; }
.productos { display: grid; grid-template-columns: repeat(auto-fill, minmax(240px, 1fr)); gap: 20px; }
.productos img { width: 100%; border-radius: 12px; }
footer { background: #111; color: #ccc; padding: 24px; text-align: center; }
footer a { color: #fff; }
@media (max-width: 600px) { .portada h1 { font-size: 30px; } }
</style>

Guarda y recarga el navegador. Ya tienes una página que se ve profesional y se adapta al celular.

Paso 9: revísala como cliente

Antes de publicarla, ábrela en tu celular y hazte estas preguntas:

  • ¿Se entiende en cinco segundos qué vendo y dónde?
  • ¿El botón de WhatsApp abre el chat con el mensaje correcto?
  • ¿Las fotos cargan rápido?
  • ¿La dirección y el horario están actualizados?
  • ¿Hay faltas de ortografía?

Pídele a alguien de confianza que la revise también: siempre ven cosas que tú no.

Paso 10: súbela a internet

Tienes varias opciones:

  • Subir la carpeta al administrador de archivos de tu hosting, dentro de public_html.
  • Usar GitHub con publicación automática, como explico en cómo publicar tu sitio con GitHub y Hostinger.
  • Usar servicios gratuitos para sitios estáticos mientras consigues tu dominio.

Después, da de alta tu sitio en Google Search Console y en tu perfil de Google Business.

Cómo usar la IA para mejorarla

Ya que entiendes la estructura, la IA se vuelve una gran aliada. Puedes pedirle:

  • "Agrega una sección de preguntas frecuentes con este formato."
  • "Haz que el menú se convierta en un botón de hamburguesa en celulares."
  • "Revisa este HTML y dime si hay errores de accesibilidad o SEO."

Como ya sabes qué hace cada parte, vas a poder revisar lo que te propone.

Agrega lo que Google necesita para entender tu negocio

Tu página ya funciona, pero puedes ayudar a Google a entenderla mejor con algunos detalles adicionales en el head.

Primero, una imagen para redes sociales. Cuando alguien comparta tu página por WhatsApp o Facebook, se mostrará una tarjeta con foto. Para controlarla, agrega las etiquetas Open Graph: og:title con el nombre, og:description con una frase y og:image con la dirección completa de una foto de tu negocio. Si no las pones, la red social elige cualquier imagen o ninguna.

Segundo, un ícono para la pestaña del navegador, llamado favicon. Basta con un archivo pequeño de tu logo y una etiqueta link en el head. Parece un detalle menor, pero hace que tu sitio se vea terminado.

Tercero, los datos estructurados de negocio local. Son un bloque de código en formato JSON-LD que le dice a Google, de forma ordenada, tu nombre, dirección, teléfono, horario y tipo de negocio. No cambian lo que ve el visitante, pero ayudan a los buscadores a mostrar tu información con precisión. Te explico cómo crearlos en datos estructurados para principiantes.

Mejora la portada para que convierta

La portada de una página de negocio tiene un solo trabajo: que el visitante haga algo. Revisa que cumpla estas condiciones:

  • El título dice qué vendes y dónde. "Hamburguesas al carbón en Tampico" es mejor que "Bienvenidos".
  • El subtítulo da una razón para elegirte. Ingredientes, rapidez, precio, zona de entrega o experiencia.
  • Hay un solo botón principal. Si pones cinco botones, nadie sabe a cuál darle clic.
  • El botón se ve sin hacer scroll en el celular. Prueba en un teléfono pequeño.
  • Hay una foto real de tu producto. Las imágenes genéricas de bancos de fotos generan menos confianza.

Si tu negocio tiene reseñas en Google, puedes poner un enlace a ellas cerca del botón. La prueba social ayuda mucho a decidir.

Organiza el proyecto para crecer

Cuando tu sitio tenga más de una página, conviene ordenar la carpeta desde el principio:

  • Una carpeta img para las imágenes, con nombres descriptivos como hamburguesa-clasica.jpg en lugar de IMG_4532.jpg.
  • Un archivo de estilos compartido para que todas las páginas se vean igual.
  • Una carpeta por página, con su propio index.html, para tener direcciones limpias.

Los nombres de archivo de las imágenes también ayudan al SEO de imágenes y hacen tu proyecto más fácil de entender cuando lo retomes meses después o cuando se lo pases a la IA para que te ayude.

Mide desde el primer día

Instala una herramienta de analítica, como Google Analytics, para saber cuántas personas visitan tu página, desde dónde llegan y cuántas dan clic en el botón de WhatsApp. Sin datos no puedes saber si los cambios que haces funcionan. Una buena práctica es usar un enlace de WhatsApp con un mensaje distinto para tu sitio, como "Hola, vi su página web", para identificar qué clientes llegan desde ahí.

Preguntas frecuentes

¿Puedo tener mi página sin pagar hosting?

Hay servicios gratuitos para sitios estáticos, pero para un negocio te recomiendo tu propio dominio. Da más confianza y es tuyo.

¿Cómo agrego más páginas?

Crea otro archivo, por ejemplo contacto.html, y enlázalo desde el menú. O mejor, crea carpetas con un index.html dentro para tener direcciones limpias como tusitio.com/contacto/.

¿Esta página aparecerá en Google?

Sí, cuando Google la descubra. Acelera el proceso con Search Console y con tu perfil de negocio.

Conclusión

Con un solo archivo y unas cuantas etiquetas acabas de construir la presencia digital básica de un negocio. No es un sitio perfecto, pero es tuyo, es rápido y lo entiendes. Ese conocimiento vale mucho más que una plantilla bonita que no sabes modificar.
